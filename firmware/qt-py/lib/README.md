Copyright (c) Adafruit Industries. MIT licensed — see each library's own

project's copyright.

They are included here so the whole `qt-py/` folder can be copied straight to
a board's CIRCUITPY drive. To fetch current versions instead, download the
bundle matching your CircuitPython version and copy across:

    adafruit_connection_manager   adafruit_ntp
    adafruit_max1704x             adafruit_opt4048
    adafruit_minimqtt             adafruit_register
    adafruit_requests             adafruit_ticks
